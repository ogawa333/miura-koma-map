# 三浦港 コマ地図メーカー

GitHub Pages公開用ファイルです。ZIPを解凍し、index.htmlなどのファイルとdataフォルダをリポジトリ直下にアップロードします。

Settings → Pages → Deploy from a branch → main → /(root) → Save で公開します。

出発地・目的地・経由地から、交差点だけのコマ地図を生成します。チェックポイントとミッション、交差点付近の登録済み看板・史跡などに対応します。インストールやAPIキーは不要です。

設定と作成した地図は利用中のブラウザ内に保存されます。別の公開先へ移るときは、旧アプリで「データ保存」、新アプリで「読み込む」を使います。各利用者の設定を他の人と自動共有する機能はありません。

対象範囲は三崎港・城ヶ島周辺です。道路・標識・目印の登録状況は網羅的ではありません。コース作成時は現地で確認してください。
