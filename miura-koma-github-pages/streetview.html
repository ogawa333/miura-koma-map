  1. Google Cloudでプロジェクトを選び、課金設定とStreet View Static APIを有効にします。
  2. ブラウザ用APIキーを作成し、API制限をStreet View Static APIに設定します。
  3. アプリケーション制限を「ウェブサイト」にし、利用する公開先を許可します。この公開先の例：
  4. Google Cloudで日次の割り当て上限を設定し、使用量を確認してください。
